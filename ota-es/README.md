# Canal OTA — variante FR/EN/ES (hispanophone)

Firmware Auralis **FR / Anglais / Espagnol** (sans laotien, polices sans-lao).
Destiné aux boîtiers flashés en usine avec `OTA_BASE="https://aura-lis.ca/ota-es"`.

- `firmware.bin` — image applicative (partition min_spiffs)
- `version.txt` — version encodée (entier `M*10000+m*100+p`)

Ne PAS confondre avec `/ota` (canal public FR/EN/LO) ni `/ota-marc`.
